## 시작 정책과 변경

- 출발점: LandingV3 최종 `model_9999.pt`, SHA256 `c140a2b2843bd09a52d945fc3d9d600ba6ac7c56bdbdaac22f423627f356fdd8`.
- 기존 actor/critic을 정확히 불러오며 첫 fine-tune의 optimizer/추가 학습 카운터는 새로 시작한다. 이후 재개는 optimizer와 카운터도 복원한다.
- 참조 CSV/NPZ, 팔·손 보상, 기존 지지/전역 접촉 보상, 관측·PD·제어 주기는 유지한다.
- 변경 구간: 오른발 착지 27.70–28.35초. 기존 높이별 감속 envelope를 참조 시간 및 실제 높이에 대응하는 참조 하강 속도로 대체한다. `max(0.6, min(현재 참조 하강속도, 실제 높이에 해당하는 참조 하강속도)+0.2)`를 허용 속도로 사용한다. 빠른 참조 공중 하강은 허용하면서 너무 일찍 낮아진 발은 감속하도록 유도한다. 이 수치는 hard clamp 또는 안전 한계가 아니다.
- 오른발 피크 비용을 유지하고 양발 합산 피크(3BW 초과), 양발 합산 양의 하중 증가율(80BW/s 초과), 3BW 초과 힘 적분을 추가한다. 큰 충격에서도 포화되지 않는다. 정상 지지 하중 전체에 벌점을 주지 않는다.
- 힘 적분은 현재 물리4샘플의 평균 초과량을 reward manager의 policy dt와 곱해 계산한다. 이전 물리1샘플은 증가율 계산에만 사용하므로 적분을 중복 계산하지 않는다.
- 새 구성으로 2,000 PPO 업데이트 동안 선형 전환한다. 초기에는 기존 V3 국소 보상을 완전한 강도로 유지하고, 전환 이후 V4 국소 보상을 적용한다. 기존 팔/지지/전역 보상은 계속 유지한다.
- 최종 국소 계수: 제동0.6, 조기높이0.2, 조기하중0.12, 오른발피크0.25, 오른발하중증가율0.025, 착지지연높이0.15, 착지후하중부족0.12, 양발피크0.25, 양발증가율0.05, 양발초과적분0.15.
- 샘플링: 전체 시작30%(기존 entry bank 포함), 기존 집중구간10%, 착지0.7–1.2초 전20%, 나머지 적응형40%.

## 본 학습

4096환경, 추가10,000회, 고정학습률5e-6, entropy0.0003,250회마다 체크포인트 저장. 팔/관절 추종 또는 episode length가 지속적으로 악화하면 저장 후 중단한다. 보호장치 통과가 sim2sim/실물 개선을 보장하지는 않는다.

호스트에서 컨테이너 진입:

```bash
docker exec -it --user cyclo -w /workspace/cyclo_mjlab cyclo_mjlab bash
```

컨테이너 내부:

```bash
python -u setup/taeguek07_landing_v4_20261022/launch.py 0 --num-envs 4096
```

GPU0에 다른 compute 프로세스가 있으면 실행을 거부한다. 본 학습은 자동으로 시작하지 않는다. 학습이 시작된 후 터미널 연결을 끊으면 영향을 받을 수 있으므로 세션을 유지한다.

재개는 이번 V4 본 학습의 실제 체크포인트를 지정한다:

```bash
python -u setup/taeguek07_landing_v4_20261022/launch.py 0 --num-envs 4096 \
  --resume /workspace/cyclo_mjlab/logs/rsl_rl/k1_mimic/<실제_V4_실행_폴더>/model_<번호>.pt
```

자동으로 남은 횟수만 학습한다. 다른 revision·환경수·smoke 저장본과 guard로 중단된 체크포인트는 거부한다. 동일 UID 잠금과 기존 본 학습 탐색으로 중복 시작을 방지한다.

## 검증과 채택

`test_rewards.py`: 참조추종 무벌점, 높이/시점 감속, 양발 하중분산 시 동일 합산 비용, 비포화, 정상지지 허용, 힘 적분dt, 이전표본 제외, 지연회피 방지, 기존 보상/제어 보존, 입력해시 및 재개보호 테스트32개.

`--smoke`는 요청 환경수에서8업데이트, `--cpu-smoke --smoke --num-envs 64`는 GPU를 사용하지 않는 CPU 검증이다. 짧은 실행은 구현·저장·재개 검증이며 성능 판단이 아니다. 검증 결과 파일은 `validation_cpu.json` 또는 `validation.json`을 확인한다.

학습 후 최소2,000회 간격 후보와 최종을 Original 발/50Hz 정책/200Hz 물리/전체46.38초에서 비교한다. 기본서기·참조자세 및 진입상태 변화에 대해 현재 V3보다 양발 피크 추가20% 감소,3BW 초과적분악화없음,접촉 전 속도감소,팔/손추종5%이내,접촉이탈증가없음을 임시 채택 기준으로 사용한다. 다른 착지 구간까지 확인한다. 이 기준은 물리적 안전 한계가 아니다.

## 이번 준비의 검증 상태

32개 단위 테스트와 대상 PC dry-run 통과. 동일 source/scripts/모델을 별도 경로에 복사한 노트북 GPU에서4096환경8회 업데이트와model_7.pt 저장을 확인했다. 이어서 재개 검증을 시작했으나 SSH가 `No route to host`로 끊겨 완료 결과는 확인하지 못했다. 전체강도128스텝 검증 스크립트는 준비만 됐으며 미실행이다. 따라서 저장/재개와 최종강도 GPU 검증을 모두 통과했다고 해석하지 않는다. `verification_status.json` 참고.

대상 PC의 GPU0에는 별도 `supermimic-k1-recovered-v3-resume` 작업이 남아 있다. 소유 여부가 확인되지 않아 종료하지 않았다. 본 학습은 GPU가 비어 있을 때 실행한다.
