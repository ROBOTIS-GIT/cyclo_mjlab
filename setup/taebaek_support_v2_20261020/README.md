# 태백 SupportV2: 추종을 보존하며 발 안정화

V1은 약 1000 업데이트 이후 동작 추종이 붕괴했다. V2는 V1의 중간 정책을 이어받지 않고 원본 팔 보정 model_17000.pt에서 새 optimizer로 시작한다. 모션 CSV/NPZ, physics/PD/관측/행동/기존 Mimic 및 pelvis XY 보상은 유지한다.

## 변경

| 항목 | V1 | V2 |
|---|---:|---:|
| 접촉 상실 | 0.9 | 0.2 |
| 긴 비접촉 | 0.3 | 0.05 |
| 반복 접촉 이탈 | 0.08 | 0.01 |
| 접촉점 미끄럼 | 0.45 | 0.10 |
| 누적 수평 이탈 | 0.5 | 0.08 |
| 기울기 속도 | 0.25 | 0.05 |
| 기울기 각가속도 | 0.06 | 0 (비활성) |
| 추가 높이 | 0.8 | 0.08 |
| 불필요한 상승 | 0.2 | 0.02 |
| 수평 허용/척도 | 8mm / 30mm | 20mm / 50mm |
| 높이 허용/척도 | 3mm / 8mm | 10mm / 20mm |
| 한발 지지 배수 | 1.5 | 1.2 |
| 강화 | 20→100%, 1000회 | 10→100%, 5000회 |
| 학습률 | 5e-5 | 2e-5 |
| entropy 계수 | 0.001 | 0.003 |

추가 지지 패널티 전체를 `0.6*tanh(raw/0.6)`으로 제한한 뒤 강화 계수를 적용한다. 완전 강화 때도 0.6 이하(RewardManager의 dt 곱셈 전)이며, 기본 추종 양의 보상 합 최대 6.0과 비교해 보조 목적의 크기를 제한한다. 큰 실패 영역에서는 이 보조 비용이 포화되지만 기존 추종 보상과 종료 조건은 유지된다. 발차는 발의 지지 마스크 제외, 접촉 이탈로 drift 기준점을 초기화하지 않는 동작도 유지한다.

원본과 동일한 설정 변경 효과를 구분하기 위해 `train_control.py`는 V2와 같은 환경/학습 설정에서 새 지지 보상 가중치만 0으로 만든 대조군이다. 대조군은 본 학습으로 재개할 수 없다.

## 실행과 재개

4096 envs, GPU 0, 원본 이후 총 10000 업데이트. 100회 사전 검증 후 본 실행은 그 체크포인트에서 남은 9900회를 이어간다. smoke 및 control 실행은 본 실행 선택 대상이 아니다.

```bash
docker exec -it --user 1000:1000 \
  -e MPLCONFIGDIR=/tmp/taebaek-v2-mpl \
  -e WARP_CACHE_PATH=/workspace/cyclo_mjlab/setup/taebaek_support_v1_20261020/warp_cache \
  -w /workspace/cyclo_mjlab cyclo_mjlab \
  python -u setup/taebaek_support_v2_20261020/launch.py 0 --num-envs 4096
```

컨테이너 내부에서는 마지막 python 명령만 실행한다. 실행 중 중복 실행은 잠금/GPU 검사로 거절한다. 준비 상태만 보려면 `--dry-run`을 붙인다. 캐시는 V1 폴더 아래의 컴파일 캐시를 재사용하며 V1의 보상 코드/체크포인트는 수정하지 않는다.

## 성능 저하 중단 장치

250회 저장 시점에 최근 50 업데이트의 평균 episode length를 점검한다. 500회 이후 (a) 600step=12초 미만 또는 (b) 이전 점검 최고치가 1200step 이상이고 그 절반 미만인 상태가 두 저장 시점 연속 나타나면 checkpoint를 저장하고 학습을 중단한다. 최종 저장 중복은 중복 판정하지 않는다. 재개 시 상태를 복원한다.

중단 이유는 `tracking_guard_halt.json`에 기록되며 같은 명령을 반복해도 자동 재시작하지 않는다. 해당 파일이나 checkpoint의 halt를 임의로 우회하지 말고 먼저 결과를 검토한다. 이 장치는 조기 붕괴 감지용이며 발차기 높이·잔발·실물 성능 평가를 대신하지 않는다. 본 학습의 모든 후속 checkpoint를 sim2sim 자동 평가하는 것은 아니다.

기존 모델의 역방향 회전 등 다른 문제를 해결했다는 의미는 아니다. 학습 완료 후 full-motion original sim2sim 비교가 필요하다.
