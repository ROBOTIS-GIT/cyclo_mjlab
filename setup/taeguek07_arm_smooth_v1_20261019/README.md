- 최종 `model_9999.pt`는 보완 학습 10,000회 완료를 뜻한다. 원본 7장의 기존 학습 횟수와 별개다.
- 검증용 smoke 실행은 정식 재개 검색에서 제외한다.
- GPU가 다른 계산 프로세스로 사용 중이면 시작하지 않는다. 중복 실행은 파일 잠금으로 막는다.
- Matplotlib 캐시는 UID별 `/tmp` 경로로 설정한다. 잠금 파일은 이미 일반 사용자 소유로 준비했다.

## 리워드 변경

팔 10개 관절에만 추가 비용을 준다. `h(x)=sqrt(1+x²)-1`이며, 각 항목은 팔 관절 평균이다.
`e_v=실제 관절 속도−기준 관절 속도`, `e_a=연속 두 스텝의 e_v 차이 / dt`이다.

| 추가 항목 | 비용 내부 가중치 | 정규화 / 목적 |
|---|---:|---|
| 팔 속도 오차 | 0.25 | `h(e_v / (1.5 + 0.25*abs(v_ref)))` |
| 팔 가속도 오차 | 0.12 | `h(e_a / (30 + 0.5*abs(a_ref)))` |
| 정지에 가까운 구간의 잔움직임 | 0.45 | `gate*h(e_v/0.6)` |
| 팔 자세 추종 보상 | +0.40 | `mean(exp(-wrapped_position_error² / 0.35²))` |

위 3개 비용의 합에 RewardManager 가중치 `-1`을 적용한다.
기준 속도를 중심 전후 0.1초 범위에서 최댓값으로 집계하여
`gate=1/(1+(max_abs_reference_velocity/0.35)^4)`를 계산한다.
실제 로봇 속도로 gate를 정하지 않으므로 빠르게 흔들어서 패널티를 회피할 수 없다.
빠른 동작 도중 순간적으로 속도가 0이 되는 프레임도 주변 속도가 높으면 정지 구간으로 처리하지 않는다.

새 비용은 초기 10%에서 정책 24,000스텝(24스텝/update 기준 1,000 updates)에 걸쳐 100%로 증가한다.
리셋/프레임 점프 뒤 0.15초 동안 속도 차분 비용을 제외한다.
같은 스텝에서 리워드를 다시 읽어도 이력이 중복 갱신되지 않는다.
이는 4~15Hz 주파수 필터가 아니라 시간 영역의 속도·가속도 오차 패널티다.
RewardManager의 기존 `scale_rewards_by_dt`에 따라 최종 보상에는 dt가 적용된다.

## 유지하는 내용

- 기존 TargetedV3 지지발 보상: `targeted_base.py`에 원본 정의를 보존. 재학습 시작부터 원본 학습 후반의 보상 강도를 사용하도록 `ramp_steps=1` 지정.
- 전신 action rate, 가속도, 토크 비용과 기존 추종 보상의 가중치.
- 관측, 액션, PD 게인, 모션 CSV/NPZ, 기존 시작 상태 분포와 지지발 집중 구간.
- 전체 동작이 들어가는 episode length와 기존 시작 자세 은행.
- 기존 3·4·5·7·8장 작업 및 robotis_mujoco 배포 정책.

원본 39초대 어깨 모션의 급변은 수정하지 않았다. 이번 변경이 그 구간까지 해결했다고 간주하지 않는다.

## 검증과 평가

`test_rewards.py`: 정확한 빠른 추종에 새 비용 0, 추가 진동에 비용 발생,
팔 고정 오차의 자세 보상 감소, 리셋·프레임 점프·캐시 안전성, 다리 제외, 기존 작업 격리.

`preflight.py`: 원본 체크포인트를 읽어 32환경에서 2,400 정책 스텝을 실행하고
원시 보상 유한성·gate·전체 모션 접근을 확인한다. 가중치는 업데이트하지 않는다.

`smoke_check.py`: 정식 실행과 별도의 3회 학습 및 1회 재개를 수행하고
optimizer 상태와 72→96 정책 스텝, model_2→model_3 진행을 검증한다.

이 검증은 학습 준비 확인이다. 실제 떨림 개선은 정식 학습 후 동일한 sim2sim에서 판단한다.
23.5~24초, 30.25~30.75초, 33.7~34.2초, 35.2~36.15초, 41초대의
원시 파형·되돌림·팔 자세 오차를 비교하고, 전 구간 완주·지지발 잔발·접지 안정성도 함께 확인한다.
최종 체크포인트라는 이유만으로 배포하지 말고 중간 저장본도 비교한다.

검증 완료 기록 (2026-10-19):

- 행동 테스트 5개 통과.
- 32환경 × 2,400스텝: 연속 진행 최대 46.36초, 마지막 기준 프레임 2319 도달.
- 최종 강도에서 새 비용 평균 0.05685, 최대 0.78144 (dt 곱하기 전), 유한값 확인.
- 본 학습과 동일한 4096환경으로 3 updates 실행 후 1 update 재개 성공.
- 완료 업데이트 3→4, 환경 카운터 72→96, Adam optimizer step 60→80 확인.
- 검증 모델은 정식 실행의 시작점으로 선택되지 않는다. 본 학습은 원본 9999에서 보완 0/10000으로 시작한다.
- 결과 파일: `preflight.json`, `smoke_check.json`, 파일 해시: `manifest.json`.
